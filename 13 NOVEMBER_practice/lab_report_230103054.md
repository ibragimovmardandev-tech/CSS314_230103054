### False sharing diagnosis
Largest adjacent timing reduction: 128 -> 256 bytes (1.090x). This is an observed candidate, not proof of a cache-line boundary; compare with the recorded line size and IQR. Python loop overhead and process launch can obscure coherence costs.

Stride 1: e(p) changes from 0.02898 at p=2 to 0.16037 at p=20. Rising e reflects effective overhead/contention, not necessarily a larger serial code region. Negative e can arise from superlinear effects or noise.

Stride 16: e(p) changes from -0.26680 at p=2 to 0.08958 at p=20. Rising e reflects effective overhead/contention, not necessarily a larger serial code region. Negative e can arise from superlinear effects or noise.

### Scaling diagnosis
Measured serial fraction s=0.039033, Amdahl cap=25.619; observed final strong speedup=4.348. Stage A grows with N in weak scaling, so weak efficiency can fall even with balanced Stage B. Gustafson uses each measured alpha(p).

Marginal speedup before boundary: 0.013203; after: 0.508816; absolute drop: -0.495613. Relative drop: -3753.93%.

Processes are not pinned: Pphys -> Pphys+1 is a worker-count boundary, not proof of a specific SMT or P-core/E-core transition. OS scheduling, frequency and hybrid cores affect the interpretation.

### Roofline diagnosis
Best measured blocked BS=64, tile footprint=98304 B; compare this with L1d=32768 B per instance, 65536 B per instance and L2=1310720 B per instance, 2097152 B per instance. Per-core/per-cluster cache sizes matter; aggregate cache capacity is not a per-worker budget.

ijk uses strided B reads; ikj makes B/C accesses contiguous but performs more Python-level C reads/writes. Blocking improves locality but adds interpreted loop overhead, so a larger tile or even a baseline can win. The roofline columns map each measured GFLOP/s against min(P, BW*I). For baselines, N/12 is a compulsory-traffic upper-bound intensity, not measured DRAM intensity; for blocked variants BS/12 is the requested tile model. Actual traffic was not hardware-counter measured.

The compute ceiling counts a multiply plus add as two FLOPs; CPython does not fuse them into a hardware FMA instruction. Trig operation counts are workload definitions, not hardware FLOP counts. Slice-copy bandwidth includes pool dispatch and reads+writes; cache residency, write allocation and Python overhead mean it is an empirical estimate, not a guaranteed DRAM limit. GEMM timings include resetting C.

### Scheduling diagnosis
Best dynamic C=1, 1.613x relative to block static. Block lambda=2.623, best dynamic lambda=1.002. Contiguous blocks put expensive high-index items on the last workers; cyclic distribution spreads them. C=1 requires more lock acquisitions; C=512 leaves fewer, larger chunks and can increase tail imbalance. Choose the measured minimum, subject to IQR and repeated-run noise.

Worker active runtime sums computation intervals only; lock waits are excluded. Wall time begins after all workers signal ready and includes completion/join overhead. The worker vector and lambda correspond to the median-wall-time trial. Checksums verify equivalent scheduling results.

## Measurement method

Full mode: two warmups and seven measured trials; median is sample 4, IQR is sorted sample 6 minus sample 2. Quick mode: one trial, no warmups. Phase 1 includes process launch; phases 2 and 3 reuse pools; phase 4 starts timing after worker readiness. Methods differ intentionally and cross-phase timings should not be compared directly. Stage B uses shared read-only input and returns only local reductions. All arrays are released before SharedMemory cleanup.

@dataclass

def fnv1a_hash(s):
    h = 14695981039346656037
    for b in s.encode('utf-8'):
        h = ((h ^ b) * 1099511628211) & 0xFFFFFFFFFFFFFFFF
    return h

def run_benchmark(fn, warmup=2, runs=7):
    for _ in range(warmup):
        fn()
    samples = []
    for _ in range(runs):
        t = time.perf_counter_ns()
        fn()
        samples.append((time.perf_counter_ns()-t)/1e6)
    samples.sort()
    return BenchStats(samples[0], samples[runs//2], samples[3*runs//4]-samples[runs//4])

def bounds(n,p):

def fs_worker(name, slot, iters):

def processes(fn,args):

    for p in ps: p.start()

def gemm_worker(job):
    names,N,lo,hi,variant,bs=job
    sh=[shared_memory.SharedMemory(name=x) for x in names]
    A,B,C=[s.buf.cast('d') for s in sh]
    for i in range(lo*N,hi*N): C[i]=0.0
    if variant=='ijk':
        for i in range(lo,hi):
            for j in range(N):
                acc=0.0
                for k in range(N): acc+=A[i*N+k]*B[k*N+j]
                C[i*N+j]=acc
    elif variant=='ikj':
        for i in range(lo,hi):
            for k in range(N):
                aik=A[i*N+k]
                for j in range(N): C[i*N+j]+=aik*B[k*N+j]
    else:
        for ii in range(lo,hi,bs):
            for jj in range(0,N,bs):
                for kk in range(0,N,bs):

                            aik=A[i*N+k]
                            for j in range(jj,min(jj+bs,N)): C[i*N+j]+=aik*B[k*N+j]
    del A,B,C
    for s in sh: s.close()

def schedule_worker(name,N,p,rank,mode,chunk,counter,times,checks,ready,start):
    shm=shared_memory.SharedMemory(name=name)
    out=shm.buf.cast('d')
    ready.put(rank); start.wait()
    total=0.0; active=0.0
    def work(indices):
        nonlocal total,active
        t=time.perf_counter()
        for i in indices:
            x=0.1+i*1e-6
            for _ in range(1+(i*i)//1600):
                x=math.sqrt(abs(math.sin(x)+math.cos(x))+0.1)
            out[i]=x; total+=x
        active+=time.perf_counter()-t
    if mode=='block':
        lo,hi=bounds(N,p)[rank]; work(range(lo,hi))
    elif mode=='cyclic': work(range(rank,N,p))
    else:
        while True:
            with counter.get_lock():
                lo=counter.value; counter.value+=chunk
            if lo>=N: break
            work(range(lo,min(lo+chunk,N)))
    times[rank]=active; checks[rank]=total
    del out
    shm.close()

            processes(fs_worker,[(shm.name,i*stride,hi-lo) for i,(lo,hi) in enumerate(bounds(M,p))])
        row={'kind':kind,'p':p,'stride':stride,'bytes':stride*8,**bench(trial,args.quick)}
        row['Mops_s']=M/row['median_ms']/1000
        rows.append(row); return row
    try:
        sweep={s:measure(pphys,s,'stride') for s in [1,2,4,8,16,32]}
        ps=[]; p=1
        while p<=plog: ps.append(p); p*=2
        if plog not in ps: ps.append(plog)
        for s in [1,16]:
            base=None
            for p in ps:
                r=measure(p,s,'scaling')
                if base is None: base=r['median_ms']
                speed=base/r['median_ms']
                r.update(speedup=speed,efficiency=speed/p,karp_flatt=None if p==1 else (1/speed-1/p)/(1-1/p))
        return {'rows':rows,'M':M,'metrics':[sweep[1]['median_ms'],sweep[16]['median_ms']]}
    finally: shm.close(); shm.unlink()

def phase2(args):
    strongN=1200 if args.quick else 1200000
    weakN=200 if args.quick else 200000
    rows=[]
    for kind in ['strong','weak']:
        base=None
        for p in range(1,args.logical+1):
            N=strongN if kind=='strong' else p*weakN
            shm=shared_memory.SharedMemory(create=True,size=N*8)
            view=shm.buf.cast('d')
            for i in range(N): view[i]=(i%101)/101
            del view
            ast=[]
            try:
                with CTX.Pool(p) as pool:
                    jobs=[(shm.name,lo,hi) for lo,hi in bounds(N,p)]
                    pool.map(stage_b,jobs) # initialize persistent workers outside timing
                    def trial():
                        t=time.perf_counter(); stage_a(N); ast.append((time.perf_counter()-t)*1000)
                        return sum(pool.map(stage_b,jobs))
                    r={'kind':kind,'p':p,'N':N,**bench(trial,args.quick)}
                r['stage_a_ms']=statistics.median(ast[-(1 if args.quick else 7):])
                if base is None: base=r['median_ms']
                r['speedup']=base/r['median_ms']; r['efficiency']=r['speedup']/p if kind=='strong' else r['speedup']
                r['alpha']=r['stage_a_ms']/r['median_ms']; r['gustafson']=p-r['alpha']*(p-1)
                rows.append(r)
            finally: shm.close(); shm.unlink()
    ss=[r for r in rows if r['kind']=='strong']; ww=[r for r in rows if r['kind']=='weak']
    return {'rows':rows,'serial_fraction':ss[0]['alpha'],'amdahl_cap':1/ss[0]['alpha'],'metrics':[ss[-1]['speedup'],ww[-1]['gustafson']]}

def phase3(args):
    p=args.physical; size=64000 if args.quick else 64000000
    loops=1000 if args.quick else 1875000 # 16 multiply-add pairs = 32 FLOPs
    memory=[shared_memory.SharedMemory(create=True,size=size) for _ in range(2)]
    try:
        for s in memory: s.buf[:]=b'\x01'*size # first-touch outside timing
        with CTX.Pool(p) as pool:
            jobs=[(memory[0].name,memory[1].name,lo,hi) for lo,hi in bounds(size,p)]
            pool.map(copy_worker,jobs)
            bandwidth=bench(lambda:pool.map(copy_worker,jobs),args.quick)
            compute=bench(lambda:pool.map(compute_worker,[loops]*p),args.quick)
        bw=2*size/(bandwidth['median_ms']*1e6)
        peak=p*loops*32/(compute['median_ms']*1e6)
    finally:
        for s in memory: s.close(); s.unlink()
    N=24 if args.quick else 256
    memory=[shared_memory.SharedMemory(create=True,size=N*N*8) for _ in range(3)]
    rows=[]; ref=None
    try:
        for idx,s in enumerate(memory[:2]):
            v=s.buf.cast('d')
            for i in range(N*N): v[i]=((i*7+idx*3)%23-11)/23
            del v
        with CTX.Pool(p) as pool:
            pool.map(compute_worker,[1]*p)
            for variant,bs in [('ijk',0),('ikj',0)]+[('blocked',b) for b in [8,16,32,64,96,128]]:
                jobs=[([s.name for s in memory],N,lo,hi,variant,bs) for lo,hi in bounds(N,p)]
                r={'variant':variant,'BS':bs,**bench(lambda:pool.map(gemm_worker,jobs),args.quick)}
                v=memory[2].buf.cast('d'); current=list(v); del v
                if variant=='ijk': ref=current
                r['max_error']=max(abs(a-b) for a,b in zip(ref,current))
                if r['max_error']>=1e-9: raise AssertionError('GEMM validation failed')
                if variant=='ikj': ref=current
                r['GFLOPs']=2*N**3/(r['median_ms']*1e6)
                r['tile_bytes']=3*bs*bs*8 if bs else None
                # Compulsory traffic lower bound for baseline variants; tiled model for variant 3.
                r['intensity']=bs/12 if bs else N/12
                r['roof_GFLOPs']=min(peak,bw*r['intensity'])
                rows.append(r)
        best=min((r for r in rows if r['variant']=='blocked'),key=lambda r:r['median_ms'])
        return {'N':N,'bandwidth_stats':bandwidth,'compute_stats':compute,'bandwidth_GBs':bw,'compute_GFLOPs':peak,'ridge':peak/bw,'best_BS':best['BS'],'rows':rows,'metrics':[rows[0]['GFLOPs'],best['GFLOPs']]}
    finally:
        for s in memory: s.close(); s.unlink()

def phase4(args):
    p=args.physical; N=100 if args.quick else 8000
    shm=shared_memory.SharedMemory(create=True,size=N*8); rows=[]; reference=None
    try:
        for mode,chunk in [('block',0),('cyclic',0)]+[('dynamic',c) for c in [1,8,64,512]]:
            samples=[]; workers=[]; checksums=[]
            for run in range(1 if args.quick else 9):
                counter=CTX.Value('i',0); times=CTX.Array('d',p); checks=CTX.Array('d',p)
                ready=CTX.Queue(); start=CTX.Event()
                ps=[CTX.Process(target=schedule_worker,args=(shm.name,N,p,i,mode,chunk,counter,times,checks,ready,start)) for i in range(p)]
                for proc in ps: proc.start()
                for _ in ps: ready.get(timeout=120)
                t=time.perf_counter(); start.set()
                for proc in ps: proc.join()
                wall=(time.perf_counter()-t)*1000
                if any(proc.exitcode for proc in ps): raise RuntimeError('Scheduling worker failed')
                ready.close(); ready.join_thread()
                checksum=sum(checks)
                if reference is None: reference=checksum
                if not math.isclose(checksum,reference,rel_tol=1e-11): raise AssertionError('Schedule mismatch')
                if args.quick or run>=2:
                    samples.append(wall); workers.append(list(times)); checksums.append(checksum)
            ix=sorted(range(len(samples)),key=lambda i:samples[i])[len(samples)//2]
            ts=workers[ix]; ordered=sorted(samples)
            rows.append({'strategy':mode,'chunk':chunk,'min_ms':min(samples),'median_ms':samples[ix],'iqr_ms':ordered[3*len(samples)//4]-ordered[len(samples)//4],'lambda':max(ts)/(sum(ts)/p),'worker_seconds':ts,'checksum':checksums[ix]})
        best=min((r for r in rows if r['strategy']=='dynamic'),key=lambda r:r['median_ms'])
        return {'N':N,'rows':rows,'best_chunk':best['chunk'],'metrics':[rows[0]['median_ms'],best['median_ms']]}
    finally: shm.close(); shm.unlink()

def hardware_info():
    data={'CPU':platform.processor() or 'unknown','physical_cores':None,'logical_threads':mp.cpu_count(),'cache_line_bytes':None,'L1d':None,'L2':None,'L3':None,'OS':platform.platform(),'Python':platform.python_version()}
    try:
        if platform.system()=='Windows':
            raw=subprocess.check_output(['powershell','-NoProfile','-Command','Get-CimInstance Win32_Processor | Select-Object Name,NumberOfCores,NumberOfLogicalProcessors,L2CacheSize,L3CacheSize | ConvertTo-Json'],text=True)
            cpus=json.loads(raw); cpus=cpus if isinstance(cpus,list) else [cpus]
            data.update(CPU=cpus[0]['Name'],physical_cores=sum(c['NumberOfCores'] for c in cpus),L2=str(cpus[0]['L2CacheSize'])+' KiB (WMI)',L3=str(cpus[0]['L3CacheSize'])+' KiB (WMI)')
            class Cache(ctypes.Structure):
                _fields_=[('level',ctypes.c_ubyte),('assoc',ctypes.c_ubyte),('line',ctypes.c_ushort),('size',ctypes.c_ulong),('kind',ctypes.c_int)]
            class Union(ctypes.Union):
                _fields_=[('cache',Cache),('reserved',ctypes.c_ulonglong*2)]
            class Info(ctypes.Structure):
                _fields_=[('mask',ctypes.c_size_t),('relationship',ctypes.c_int),('u',Union)]
            api=ctypes.WinDLL('kernel32',use_last_error=True).GetLogicalProcessorInformation
            length=ctypes.c_ulong(0)
            api(None,ctypes.byref(length))
            buf=ctypes.create_string_buffer(length.value)
            if api(buf,ctypes.byref(length)):
                entries=ctypes.cast(buf,ctypes.POINTER(Info))
                caches={1:set(),2:set(),3:set()}; lines=set()
                for idx in range(length.value//ctypes.sizeof(Info)):
                    item=entries[idx]
                    if item.relationship==2:
                        c=item.u.cache
                        if c.level in caches and c.kind in (0,1):
                            caches[c.level].add(c.size); lines.add(c.line)
                for level,key in [(1,'L1d'),(2,'L2'),(3,'L3')]:
                    if caches[level]: data[key]=', '.join(str(v)+' B per instance' for v in sorted(caches[level]))
                if lines: data['cache_line_bytes']=min(lines)
        elif platform.system()=='Darwin':
            def sysctl(key): return subprocess.check_output(['sysctl','-n',key],text=True).strip()
            data.update(CPU=sysctl('machdep.cpu.brand_string'),physical_cores=int(sysctl('hw.physicalcpu')),cache_line_bytes=int(sysctl('hw.cachelinesize')),L1d=sysctl('hw.l1dcachesize')+' B',L2=sysctl('hw.l2cachesize')+' B',L3=sysctl('hw.l3cachesize')+' B')
        else:
            raw=json.loads(subprocess.check_output(['lscpu','-J'],text=True,stderr=subprocess.DEVNULL))
            fields={r['field'].rstrip(':'):r['data'] for r in raw['lscpu']}
            data.update(CPU=fields.get('Model name'),physical_cores=int(fields['Core(s) per socket'])*int(fields['Socket(s)']),L1d=fields.get('L1d cache'),L2=fields.get('L2 cache'),L3=fields.get('L3 cache'))
            data['cache_line_bytes']=int(subprocess.check_output(['getconf','LEVEL1_DCACHE_LINESIZE'],text=True))
    except (OSError,ValueError,KeyError,subprocess.SubprocessError): pass
    return data

def table(rows):
    if not rows: return ''
    keys=list(rows[0])
    def fmt(v):
        if v is None: return 'N/A'
        if isinstance(v,float): return f'{v:.6g}'
        return str(v).replace('|','/')
    return '| '+' | '.join(keys)+' |\n| '+' | '.join(['---']*len(keys))+' |\n'+'\n'.join('| '+' | '.join(fmt(r.get(k)) for k in keys)+' |' for r in rows)+'\n'

def main(default_phase=None):

    parser.add_argument('--student-id',type=int,default=230103054)
    parser.add_argument('--quick',action='store_true')
    parser.add_argument('--physical',type=int)
    parser.add_argument('--logical',type=int)
    parser.add_argument('--hardware',type=Path,default=Path('hardware.json'))
    parser.add_argument('--phase',type=int,choices=range(5),default=default_phase)
    parser.add_argument('--output',type=Path)
    args=parser.parse_args()
    hw=hardware_info()
    if args.hardware.exists(): hw.update(json.loads(args.hardware.read_text(encoding='utf-8-sig')))

    args.physical=args.physical or (min(2,mp.cpu_count()) if args.quick else hw['physical_cores'])
    args.logical=args.logical or (min(2,mp.cpu_count()) if args.quick else mp.cpu_count())
    if not args.physical or not 1<=args.physical<=args.logical: parser.error('Set correct --physical and --logical counts (1 <= physical <= logical)')
    if not args.quick and args.logical!=mp.cpu_count(): parser.error('Full mode must sweep mp.cpu_count() logical processors')
    if not args.quick and ((args.physical-1)*32>=512 or (args.logical-1)*16>=512): parser.error('Assignment 4096-byte block cannot fit requested slots. Consult instructor; do not silently change block size.')
    if not args.quick and any(hw.get(k) is None for k in ['cache_line_bytes','L1d','L2','L3']):
        parser.error('Complete missing cache metadata in hardware.json; see README_RU.md')
    args.output=args.output or Path('smoke_results' if args.quick else 'results')
    args.output.mkdir(parents=True,exist_ok=True)
    state={}; statepath=args.output/'telemetry.json'
    config={'student_id':args.student_id,'quick':args.quick,'physical':args.physical,'logical':args.logical,'hardware':hw}
    if args.phase is not None and args.phase>0:

        report(args,state)
        print(result['tag'],flush=True)
    print(f'Report saved in {args.output.resolve()}',flush=True)
